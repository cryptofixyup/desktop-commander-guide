# desktop-commander-guide

Explain what Desktop Commander can do, suggest relevant use cases and first tasks, help users choose models and AI access options, explain Apps, MCPs, and skills, and troubleshoot common setup or product-understanding questions.

## About

This repository contains guidance and documentation for Desktop Commander, a technical assistant that works on your actual computer and connected apps.

## What's Inside

- Desktop Commander capability overview
- AI access and billing information
- Model selection guidance
- Apps and MCPs (Model Context Protocol) connections
- Skills and automation
- Troubleshooting and common questions
